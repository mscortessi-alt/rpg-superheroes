# La UPA fue tomada

Proyecto Integrador Final - Informatica I - UPA

Grupo 8 - RPG por turnos - Superheroes

**Integrantes:** Monique Salustre y Helena Dominguez

**Profesor:** Gustavo Galeano


## De que se trata

La profe Diana encendio el Nucleo Cuantico en el laboratorio de fisica y ahora controla la mente de casi toda la UPA. A unos pocos estudiantes la onda les dio superpoderes. Elegis uno y tenes que recorrer la universidad piso por piso hasta llegar al auditorio y detenerla.

**Heroes:** Thiago, Patus, Edisson, Jose y Mayra.

**Villanos:** Ruben, Frau Ana Maria, la Cantinera, Sebas y Esteban, Luciana, Meybel, Roger, Johan, Juan Ubaldo y la profe Diana.

## Lo que pide la consigna

- Clases con encapsulamiento (atributos private con getters y setters)
- Herencia y polimorfismo: Personaje -> Heroe / Villano -> cada personaje
- Estructuras de datos: ArrayList (mochila, enemigos, ranking) y Queue (recorrido)
- Excepcion propia: AccionInvalidaException
- Busqueda lineal: buscarItem() y buscarMejorDe()
- Ordenamientos: burbuja (mochila), insercion (cantina) y seleccion (ranking)
- Archivo: el ranking se guarda en ranking.txt

El diagrama de clases esta en [docs/diagrama-clases.png](docs/diagrama-clases.png)

## Como jugar

```
javac -encoding UTF-8 -d bin src/*.java
java -cp bin Main
```
